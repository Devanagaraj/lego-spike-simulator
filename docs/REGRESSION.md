# Regression checklist

The checklist also covers the supplied `FLLAttachmentBot.mpd`: load it from the robot menu, verify A=left/B=right from the gear-facing back view, automatic missing-part reuse/download, opposite E-gear rotation, and lift-piece motion.

1. Run `npm run test:simulation`. It uses the bundled Simple Bot MPD and FLL Attachment Bot IO models. Tests assert both tire heights match the model floor, idle yaw is zero, equal wheel travel is straight, one powered wheel arcs, a commanded 90° turn begins near zero and reaches the target, a moved motor takes its wheel link, and a tool motor moves without drive wheels.
2. Run `npm run check` and `npm run build`. A successful build alone does not verify motor behavior.
3. In the browser, load each preset and confirm the idle robot does not jump or flash when Play begins. Orbit/zoom first and confirm the same view remains after Play. The loading overlay should disappear only after the model and map have rendered.
4. Open **Connect ports**, **Connect wheels**, and **Gears and attachments**. Selection previews should stay still until dragged; dragging orbits and scrolling zooms. The selected mesh has a yellow outline. Moving a drive motor to an empty port must update its wheel's displayed port and motor label; moving it to an occupied port must swap both motor and wheel connections. A non-motor port cannot drive a wheel.
5. Select FLL Attachment Bot in a fresh browser profile: any missing components should first use the saved library and otherwise request the official complete ZIP. Confirm the model re-renders after resolving parts and that a failed download shows a manual Library-button fallback rather than an endless loading bar.
6. The separate LED matrix starts hidden. Minimize/close/reopen the virtual hub and LED matrix from **Panels**, and hide/restore the entire side rail. The gyro is overlaid at the scene's top right; minimize/close/reopen it. Its yaw should follow a turn; pitch and roll remain zero on the level mat. The center hub button starts/stops the program; left/right pointer presses and releases visibly change state and fire program button events.
7. Both presets must load A=left, B=right, C=colour sensor, with wheel-panel ratios A=1 and B=-1. The default load view is the gear-facing back camera with robot heading 0°. Left/right are relative to that view, not an arbitrary orbit. Forward AB must drive toward the gears; reverse must move away. A-only forward should arc right and B-only forward should arc left. Verify opposite speeds turn in place without translation.
8. Restore a pre-AB cached preset (including previous version-2/version-3 caches): wiring, old ratios, and old AC/CD movement-pair blocks migrate once, and old preset names are canonicalized to the numbered display names. Reassign a motor after migration, reload, and confirm the custom assignment survives. From the top-front view, verify gear direction and coaxial shaft motion. Check that pressing Play preserves heading and camera.
