# Simulator context

Entry points: `src/components/BlocklyComponent.svelte` owns the Blockly workspace and its initial Simple Bot sample program. `SpikeSimulatorWindow.svelte` owns the toolbar and modal open state. `SpikeSimulator.svelte` loads models, connects motors/wheels/tools, owns the running VM, and switches the *scene data* used by one persistent `ScenePreview.svelte` canvas. It also owns the collapsible virtual-hub/LED/gyro panels and Studio parts-library reuse/download. `ScenePreview.svelte` renders the map, chassis, wheel meshes and configured rotating parts. `RobotPreview.svelte` is the user-orbitable selected-part preview in connection panels.

Physics and model data: `src/lib/spike/vm.ts` contains `Hub`, `Motor`, `Wheel`, yaw, and differential-drive motion. `src/lib/spike/connections.ts` keeps wheel and tool links with a motor when its hub port changes. `src/lib/spike/presets.ts` defines the attachment robot's assumed Studio wiring and stable display names. `src/lib/ldraw/components.ts` parses LDraw and `!SPIKE_PORT`, `!SPIKE_GEARING`, and `!SPIKE_ROTATE` metadata. `src/lib/ldraw/gl.ts` compiles the model into WebGL geometry. `src/lib/robot-cache.ts` stores the configured robot in browser storage.

Presets: `src/lib/assets/robots/DifferentialDriveBot.mpd` is **1. Simple Bot** (formerly SimpleBot/Differential Drive Trainer); `DriveAndAttachmentBot.io` is **2. FLL Attachment Bot** (formerly Robot 2/Drive + Attachments Bot); `FLLAttachmentBot.mpd` is **3. FLL Attachment Bot (MPD)**, the supplied metadata-based variant. All use A=left drive and B=right drive when viewed from the gear-facing back view; C is the colour sensor where present and E/F remain tool ports. The canonical load view is the gear-facing back camera at zero heading. Forward is derived from the actual gear-vs-wheel geometry so every robot drives toward its gear end. Wheel-panel ratios are A=1 and B=-1; drive-block motor commands account for those mirrored axle signs. `configurePresetDrive` sets `hub.driveForward` so mesh orientation cannot redefine forward. Hub reset preserves this chassis direction. The sample uses AB. Robot cache `driveLayoutVersion: 4` migrates older preset wiring and previous ratio layouts once, preserving later custom assignments. Blockly marker `spike-drive-layout-ab-v1` migrates cached AC/CD movement pairs once as requested. Any loaded robot with unresolved parts triggers cached-library reuse, official ZIP download, then a visible manual fallback. `isAttachmentDriveName` and `isFllMpdDriveName` recognize new and legacy cached names.

Coordinates: the LDraw compiler converts model units to millimetres and flips the LDraw Y/Z axes. The robot's X/Z position and yaw are in `sceneStore`; its starting Y is calculated from the wheel contact patch (or the compiled bounding box for wheel-less models). The camera can orbit independently and its tilt is not robot yaw. Startup and preset loads use the gear-facing robot view with a little extra camera distance; the map view remains available from the toolbar. The running scene is a copy of the idle scene, while the same canvas remains mounted across Play/Stop.

BIOGLOW: `src/lib/assets/scenes/bioglow-wireframe.jpg` is the supplied wireframe map. The toolbar and `LoadScene.svelte` load it at 2360 x 1140 mm and clear placeholder scene objects. The scene editor exposes a bounded robot start X/Z/heading dialog; `SpikeSimulatorWindow.svelte` also provides direct Wire map and Robot view / Map view controls.

Known limits: only a flat two-wheel differential drive is modeled. Visual attachments rotate by explicit motor/axis/ratio links; coaxial axles and the supplied MPD's lift pieces are grouped with their gears, but general gear-train inference, gravity, collisions, and force simulation are not implemented. `loadModel` negates `!SPIKE_GEARING` metadata; preset runtime wheel ratios are A=1, B=-1. Tests invoke actual movement block handlers and assert travel toward each model's gear positions, left/right wheel and motor locations, backward travel, single-wheel turn signs and 90-degree tank turns.
